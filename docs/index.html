01Features

Browse, audition, trim, export. The things you do fifty times an hour are one key or one drag.

Instant search
Filter by name, channels, duration, favorites, or category. Results update as you type.
Auto-categorize
Files are tagged on index from their names and paths. Can be turned off in Settings.
Manual overrides
Reassign or clear any category. Your changes survive reindexes.
Waveform preview
Click to seek, drag to select, loop the selection. Auto-play as you arrow through the list.
Region export
Export just the selected slice, or drag it straight out of the app.

Batch exporter
WAV at 16, 24 or 32-bit, or OGG Vorbis. Any sample rate. Numbered or lettered output names.
Favorites

Sortable table
Sort by name, category, duration, channels, rate, or size.
Reveal in folder
Jump to any file in your system file manager.
Keyboard-driven

02How it stores things

The index lives inside the folder it describes.

D:/Samples/ ├── slip-sound.db ← SQLite index, categories, favorites ├── Ambience/ ├── Foley/ └── Weapons/

Every folder you open gets its own SQLite file at its root. Index once, and reopening is instant. Reindex only when you've added or changed files. There's no central catalog and no hidden app-data blob, so the index moves with the folder to another drive or machine.

04MCP server

Optional. Lets Claude Desktop, Cursor, or VS Code search, tag, and export your library.

Off by default; enable it in Settings. It binds to 127.0.0.1 only, mints a new bearer token each launch, and checks Origin/Host headers to block browser DNS-rebinding. Settings shows the URL and token ready to paste into an mcpServers block.
